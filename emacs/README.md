## Notes
* <C-h> is replacable by <F1>?
* Comments in Emacs have levels
  * ; is an inline comment (usually on the right, supposedly next to code)
  * ;; is a code comment (on code level indentation)
  * ;;; is a header comment (usually on the left, without any indentation)
